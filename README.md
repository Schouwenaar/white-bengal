# White Bengal

A soft pastel theme for Claude Code with pixel-art details: a dusk sky in lavender, pink and peach, mint hills, bamboo, snow with paw prints, and a little white Bengal tiger sitting in the corner of your window.

![Preview of the White Bengal backdrop](assets/preview.png)

## What you get

- **Backdrop** — a pixel-art scene drawn behind the conversation in the Claude desktop and mobile apps. The tiger stays in the bottom-right corner at any window size.
- **App colors** — snow white and lavender grey surfaces, an ice-blue accent, and pink, mint and amber for errors, success and warnings. There is a light and a dark version, and the theme follows your own mode.
- **Prompt band** — a tiny tiger face and three pastel paw prints above the message box (desktop app).
- **A command** — `/white-bengal` switches the theme on or off. `/white-bengal on` and `/white-bengal off` also work (`aan` and `uit` too).

The terminal and editor extensions draw no backdrop or colors, so there the theme does nothing visible.

## Install

In the Claude desktop app: click **+** next to the message box, then **Plugins**, **Add marketplace**, enter `Schouwenaar/white-bengal`, then **Add plugin**.

At the prompt of a Claude Code terminal session:

```
/plugin install white-bengal --marketplace Schouwenaar/white-bengal
```

Or from a shell:

```bash
claude plugin install white-bengal --marketplace Schouwenaar/white-bengal
```

Answer `y` to add the marketplace, then pick a scope (the user scope makes the theme load in every session). A theme installed from a terminal at the user scope also shows up in the desktop app.

## Make it load every time

The tiger and the prompt band are drawn by the plugin while a session runs, so they only show in sessions where the plugin is loaded. (The app can keep the colors from an earlier session, which is why you may see the colors without the tiger.)

**For your whole account.** Install it once in the Claude desktop app as described above. Local sessions and new cloud sessions then load it.

**For one repository, in the code.** Commit a `.claude/settings.json` like this to the repository's default branch. Every session opened on that repository, cloud sessions included, then installs and loads the theme by itself:

```json
{
  "extraKnownMarketplaces": {
    "white-bengal": {
      "source": { "source": "github", "repo": "Schouwenaar/white-bengal" }
    }
  },
  "enabledPlugins": {
    "white-bengal@white-bengal": true
  }
}
```

If the repository already has a `.claude/settings.json`, add these two keys to it. This repository carries the same file, so sessions opened here load the theme too.

The "New session" screen has no session yet, so it shows at most the colors; the tiger appears once the session starts.

## Notes

- Only one theme can be active in a session. `/white-bengal off` clears the active theme, whichever mod set it.
- The labels the mod shows are in Dutch ("witte bengaal").
- All artwork is original and generated by the mod's own code; there are no image files to load.
